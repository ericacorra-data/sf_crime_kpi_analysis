# KPI-driven Crime Analysis - San Francisco (2016)
KPI-driven analysis of urban crime to support police resource allocation
## Objective
Analyze urban crime patterns in San Francisco to identify high-risk areas, time ranges and crime types, supporting data-driven police resource allocation decisions.
## Dataset 
San Francisco Police Department Incidents (2016), sourced from the San Francisco Open Data portal.
A random sample of 10000 incidents was extracted to improve computational efficiency during exploratory analysis.
## Key KPIs
- Total crime volume
- Top crime category share
- Peak crime day and time range
- Most critical police districts
- Crime hotspot concentration
## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly, Folium
